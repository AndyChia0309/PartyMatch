# 功能地圖

依開發範疇分類整理，每項功能可點進對應的流程文件查看詳細設計。

## 核心交易流程

| 功能 | 說明 | 詳細文件 |
|---|---|---|
| 探索群組 | 瀏覽所有招募中的群組，依服務分類篩選，依建立時間排序 | [探索群組流程](../flows/explore-flow.md) |
| 條件搜尋 | 依服務、方案、預算、信用分數、群組年齡等多重條件精準媒合推薦群組 | [條件搜尋流程](../flows/condition-search-flow.md) |
| 建立群組 | 4 步驟表單建立共享群組（服務／方案／設定／預覽），金額與方案由伺服器端重新驗證 | [建立群組流程](../flows/create-group-flow.md) |
| 申請與審核 | 送出申請即代管扣款，團主審核通過建立成員，拒絕或取消則原路退款 | [申請流程](../flows/apply-join-flow.md)・[審核流程](../flows/approval-flow.md) |
| 群組生命週期狀態機 | 招募 → 額滿 → 服務設定 → 啟用 → 確認期 → 服務進行中 → 續訂／結束，各階段對應可執行的操作 | [群組狀態機](../flows/group-state-machine.md) |
| 共享模式 | 依服務類型決定成員要填 Email、Apple ID、Google 帳戶、邀請碼，或提取團主提供的共用帳密 | [共享模式](./sharing-modes.md) |
| PM 幣代管與撥款 | 平台內部代幣，申請當下即代管扣款，服務確認無誤才撥款給團主 | [PM 幣與代管流程](../flows/payment-token-flow.md) |
| 續訂 | 到期前系統提醒，團主手動開啟續訂，成員可個別選擇是否繼續 | [續訂流程](../flows/renewal-flow.md) |
| 申訴與裁定 | 服務異常時可申訴，雙方優先自行協調，協調未果由管理員裁定金流歸屬 | [申訴流程](../flows/dispute-flow.md) |

## 信任與安全機制

- **信用分數**：依使用者行為即時增減，可作為群組申請門檻，並設有重新申請冷卻期
- **可選評價**：服務確認後團主與成員可自行決定是否評價，之後也能補評或更新評價，評分回饋至信用分數
- **敏感資料保護**：共用帳密加密儲存；群組與成員資料依角色動態遮罩後才回傳給前端

## 帳號與個人設定

- **帳號設定**：個人資料、隱私偏好（大頭照顯示開關）、線上狀態自動偵測
- **帳號停用與自助恢復**：可自行停用帳號，一段時間內可自助恢復，逾期需聯絡客服
- **PM 幣**：餘額查詢、模擬儲值、交易紀錄
- **收藏群組**：先收藏心動群組，之後再比較

## 管理員後台

獨立路由與獨立登入機制，不與一般使用者共用同一套介面，提供平台總覽統計、系統公告／私訊發送、帳號管理、申訴裁定等功能。
